# FoodCalorieRecognizer

Приложение для распознавания продуктов питания по фотографии и подсчета калорий.

## Возможности

- Выбор фото из галереи устройства
- Съемка фото на камеру телефона
- Распознавание 6 классов продуктов (Pizza, Salad, Apple, Coffee, Pasta, Pilaf)
- Отображение процента уверенности распознавания
- Вывод калорийности продукта
- Простой и интуитивно понятный интерфейс

## Технологии

- Android SDK (minSdk 24, targetSdk 34)
- TensorFlow Lite 2.10.0
- CameraX
- Java

## Установка и запуск

1. Установите Android Studio Koala или более позднюю версию
2. Клонируйте репозиторий
3. 3. Откройте проект в Android Studio
4. Подключите Android-устройство с включенной отладкой по USB или запустите эмулятор
5. Нажмите зеленую кнопку Run

## Использование

1. Запустите приложение на устройстве
2. Нажмите кнопку «Галерея» для выбора фото из галереи или «Камера» для съемки
3. Выберите или сфотографируйте продукт питания
4. Приложение покажет:
- Название распознанного продукта
- Процент уверенности в распознавании
- Калорийность продукта

## Рекомендации

- Используйте четкие фотографии при хорошем освещении
- Продукт должен занимать большую часть кадра
- Для точного распознавания рекомендуется использовать продукты, на которых обучена модель (Pizza, Salad, Apple, Coffee, Pasta, Pilaf)
